## Resumen ejecutivo

Quinta ronda, de **UX de terminal**, con 6 incidencias reportadas
directamente por el usuario tras usar `./wormy shell` de verdad:
(1) prompt con markup rich literal (`[dim]○ IDLE[/]…`), (2) barra de
progreso que imprimía una línea por host (100+ líneas), (3) muro de ~90
INFO al arrancar shell, (4) `exit` imprimía el FINAL REPORT duplicado con
duración negativa (`-1 day, 23:59:59…`) y subsecciones en ruido, (5) la
tabla de comandos sin color y "exit feo", (6) el help raíz no explicaba
cómo levantar la web. Además pidió mejores imágenes/GIFs del README
("letras ilegibles / destructuradas").

Causas raíz encontradas (no parches cosméticos):

1. **Prompt**: `cmd.Cmd` imprime `self.prompt` vía `input()`/stdout
   crudo — el markup rich nunca se renderiza ahí. Solución: ANSI real
   con colorama si `console.is_terminal`, texto plano si pipe.
2. **Barra de progreso**: `_print_progress` YA usaba `\r`, pero
   `do_scan`/`do_run` envolvían el scan en `console.status(...)` — el
   spinner de Rich reescribe el cursor y rompe la sobreescritura de
   línea → 100 líneas. Solución: cabecera simple en vez de spinner +
   barra con modo TTY (\r in-place) y modo pipe (hitos ~10%).
3. **Doble FINAL REPORT**: `do_exit` llama `worm.shutdown()` y el
   `finally` de `cmd_shell` lo llamaba OTRA VEZ. Solución:
   `shutdown()` idempotente (flag `_shutdown_started` a la entrada).
4. **Duración negativa**: `print_final_report` resolvía `end_time`
   ANTES que `start_time`; con sesión sin `run`, start quedaba 2µs
   después de end. Solución: start primero (honrando
   `self.start_time` del engine), clamp end≥start, duración
   humanizada (0.42s / 1.5m / 1.5h).
5. **Muro de INFO**: handler de consola del logger a WARNING en modo
   shell (archivo intacto, `logs/worm_*.log`), flag `--verbose` para
   restaurar. "Logger initialized" pasa a debug (consola limpia en
   todos los comandos). El nivel se restaura al salir (embedders/tests).

Respuesta a "¿la herramienta debe estar todo en inglés?": verificado
programáticamente (AST walk sobre print/log/console de todo el repo):
**0 strings en español** en superficies user-facing. Las capturas
regeneradas y todo el texto nuevo de esta ronda: inglés.

## Mejoras concretas

### Mejora 1 — REPL visual: prompt ANSI + help coloreado

- `shell.py::_update_prompt`: `○ IDLE`/`● RUNNING` con Fore/Style de
  colorama (verde/cyan/dim) en TTY; texto plano si no. Testeado en
  ambos modos (sin markup crudo NUNCA).
- `do_help`: celdas `Text` dos tonos — comando en bold cyan, hints de
  uso (`[pro|basic]`, `<ip>`) en dim italic. Sin `escape()` (Text no
  parsea markup) → cero regresión de corchetes.

### Mejora 2 — Exit limpio + shell silencioso

- `mixin_base.shutdown()` idempotente: report ×1, componentes ×1
  aunque lo llamen exit/kill-switch/wrapper (el paste del usuario
  mostraba TODO duplicado, incluido el error de ResilientC2Engine).
- `print_final_report` rediseñado: panel Rich "Final report —
  engagement summary", 13 KPIs, chips de hosts (verde/rojo, truncado a
  8 + "… and N more"), Success Rate solo con intentos, duración
  humanizada y clamp; subsecciones cero (creds/lateral/graph/polymorphic)
  solo si tienen datos (una sesión vacía antes vomitaba 4 bloques en
  cero); footer console "Reports written: …json · csv · txt (./reports/)"
  — antes eran solo INFO y con el shell quieto habrían desaparecido.
- `utils/logger.py`: `set_console_level()` + handler referenciado;
  "Logger initialized" → debug.
- `cli.py::cmd_shell`: `--verbose/-v` (quiet por defecto, restaura
  INFO al salir); acceso defensivo `getattr(args, "verbose", False)`
  (Namespaces de embedders).

### Mejora 3 — Scan UX + ayuda web

- `professional_scanner._print_progress`: TTY → `\r` + flush (UNA
  línea); pipe → hitos ~10% + final (acotado, `scan --json | jq`
  limpio). `print()` final solo en TTY.
- `do_scan`/`do_run`: cabeceras simples ("Scanning network...") en
  lugar de `console.status` (el spinner era el conflicto).
- `EPILOG_EXAMPLES`: `run --dry-run --web  # engine + web dashboard
  at 127.0.0.1:5000` + hint de --verbose en shell.

### Mejora 4 — Media del README legible (82 columnas)
