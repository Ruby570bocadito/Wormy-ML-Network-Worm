## Detalle de las mejoras

### Mejora 1 — Portada y medios reales

**Diseño de captura.** Grabadora pty propia (stdout a un pty con
winsize 100 cols, stderr a devnull → sin ruido loguru, colores Rich
vivos). El flujo: ANSI crudo → `Text.from_ansi` → `Console.record` →
`export_svg` para PNGs (wrapper HTML a 2×, screenshot con navegador
headless, crop exacto) y → segmentos→HTML con colores inline para el
GIF (player con chrome de terminal macOS, tecleo 26 ms/char, reveal
70–220 ms/línea, cursor parpadeante; grabado como webm y convertido con
ffmpeg palettegen/paletteuse).

**Datos honestos.** Engagements reales: A (baseline débil, sin lab: 0
hosts, 1 infectado, 2 s) vs B (con lab: 3 hosts, 4 infectados, 1 vuln,
6.7 s) vs C (cap 2: 3 hosts, 2 infectados). El GIF usa el par A→B y el
paso `prune` usa un `--reports-dir` aislado con el trío (historia
consistente: "keep 2, delete 1"). Bug de colisión de segundo de
`audit_report` esquivado (IDs separados por minutos).

**Correcciones de render descubiertas por el camino:** (a) el pty
convierte `\n`→`\r\n` y mi colapso de `\r` borraba líneas enteras —
normalizado `\r\n` primero; (b) el prompt del REPL llega con markup
rich literal (bug real, ver traspasos) — el pipeline lo traduce a los
estilos ANSI pretendidos y recorta en "Exiting" para no mostrar el
resumen de salida (que además enseña el bug de duración negativa).
